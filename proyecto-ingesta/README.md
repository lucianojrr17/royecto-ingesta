# Proyecto de Ingesta de Ventas

Este proyecto automatiza el procesamiento de ventas.

## Instrucciones
1. Coloca el archivo `ventas.csv` en la carpeta `origen/`.
2. Ejecuta la ingesta: `python ingesta.py`
3. Ejecuta el procesamiento: `python carga.py`

## Estructura
- `data/raw/`: Almacena los datos crudos.
- `data/processed/`: Almacena los resultados finales.
